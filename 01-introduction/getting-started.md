# Getting Started with Docker

## Docker Editions
Docker comes in two editions:

1. **Community Edition (CE)** – Free and open-source, suitable for developers and small teams.
2. **Enterprise Edition (EE)** – A paid version with enterprise-level features like image management, security, and advanced orchestration tools.

For this guide, we will use the **Community Edition (CE)**.

## Installation Options
Docker CE is available for:
- **Linux**
- **Mac**
- **Windows**
- **Cloud platforms** (AWS, Azure, etc.)

### Mac & Windows Users
You have two options:
1. **Use a Linux Virtual Machine** – Install a Linux VM via VirtualBox or another virtualization platform and follow along with the Linux installation steps.
2. **Install Docker Desktop** – Native applications for Mac and Windows are available.

For native installations, refer to the official Docker documentation before proceeding.
